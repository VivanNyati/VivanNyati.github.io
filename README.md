# Science of Me

This website, titled Science of Me, helps children and young adults explore science by investigating psychological phenomena.

**[Visit the website](https://vivannyati.github.io)**

## Built With

Jekyll · HTML · SCSS · JavaScript · Bootstrap 4 · jQuery · GitHub Pages

## Run Your Own Copy

Want to adapt this site for your own program? Fork this repository, then clone your fork to make changes and preview them locally.

You'll need **Git, Ruby, and Bundler** installed.

```bash
git clone https://github.com/YOUR-USERNAME/VivanNyati.github.io.git
cd VivanNyati.github.io
bundle install
bundle exec jekyll serve
```

Open [localhost:4000](http://localhost:4000) to preview your changes.

Update `_config.yml` with your site's name, URL, and contact information. Experiment listings and search data live in `_layouts/home.html`.
